### What changed

- **DS Download Play:** `run-emu @firmware` opens the DS menu from the user's own BIOS and firmware, with the cart slot empty, so a console can receive a game from another one. A DS Download Play host takes the other consoles' replies as they come, and a console that downloaded a game rejoins after it restarts into it. The DS menu's settings are kept in a working copy of the firmware on the console. No BIOS or firmware is included.
- **Auto Join:** a new Local multiplayer mode (Spanish: *Unirse automáticamente*) that looks for a host and joins it, and never hosts (`wifi.local = autojoin`). Banana Party opens the DS menu on it when auto discovery is on, so a console receiving a game never becomes the host by mistake.
- **Wi-Fi address per console:** the DS's Wi-Fi address comes from the card's machine ID, with the generated firmware and with the user's own, the same way as the system's DS emulator. The saved Nintendo WFC settings are kept.
- **Steadier local play:** no multiplayer packet is dropped on a slow round trip, and a console whose host goes quiet keeps running.
- **Self-contained player:** the C++ and GCC runtimes are linked into the player, so it does not depend on the ones on the system.

### Installation

This package is the emulator inside [Banana Party](https://github.com/pixeladodev/banana-party) for the Anbernic **RG DS** and **RG DS Plus**. Install or update Banana Party from its latest release; it brings this version with it.
