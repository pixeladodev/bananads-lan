### What changed

- **The player is up to date with the official emulator:** it is built from the upstream commit that the system packages now, instead of the one from before it. Two of the changes upstream bring along are in this release: the in-game menu's clicks now follow the system's *Menu sounds* setting, and the microphone is turned up ten times before the noise gate, so a voice reaches the game instead of being cut off.
- **Everything else is as in 0.1.2:** Local multiplayer with Off, Auto, Auto Join, Host and Join, the Party session, DS Download Play, the Wi-Fi address per console and the saved Nintendo WFC settings are unchanged.

### Installation

This package is the emulator inside [Banana Party](https://github.com/pixeladodev/banana-party) for the Anbernic **RG DS** and **RG DS Plus**. Install or update Banana Party from its latest release; it brings this version with it.
