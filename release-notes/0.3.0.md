# BananaDS LAN 0.3.0

**BananaDS LAN** is an Apps-shelf app for BananaOS that swaps in a build of BananaDS with local wireless multiplayer. Consoles on the **same Wi-Fi network** can host or join DS sessions from the in-game **Local multiplayer** menu.

This release follows **BananaOS 0.5.3.4**. Its BananaDS is the one BananaOS 0.5.3.4 ships, with Local multiplayer added on top, so you keep everything new in the system's BananaDS.

**Devices:** Anbernic **RG DS** and **RG DS Plus**. **BananaOS 0.5.3.4** only. On BananaOS 0.5.2.2, keep BananaDS LAN 0.2.0.

### What's new

- Built on **BananaOS 0.5.3.4's BananaDS**:
  - Black caves and washed-out fog fixed in games that use fog (Pokémon Black 2 and others).
  - No crackle when fast-forward ends, and fast-forward's **Max** is kept for the next game.
  - The **DS CPU speed** setting and the per-game CPU speed go past the DSi's clock (266, 533, 1066 and 2133 MHz).
  - The left stick's diagonals are read from its tilt, so a diagonal no longer turns into Up or Down alone.
- The **Buttons** page in Settings (Nintendo DS > Buttons) keeps working in this BananaDS, as in 0.2.0.
- **Nintendo WFC** settings are still kept between launches, with a DS MAC address of its own for each console.

### Local multiplayer

- Works as in 0.2.0: **Auto** by default, or **Host** and **Join** on the Local multiplayer page.
- The session's packets go in the Wi-Fi voice queue (DSCP 46), and the optional direct link (`BANANADS_LAN_TDLS=1`) stays off by default.
- All consoles in a session need BananaDS LAN 0.3.0 on BananaOS 0.5.3.4, or desktop melonDS on the same network.

### Install or update

1. Update the console to BananaOS 0.5.3.4 first (Settings > System > Update).
2. Extract the zip. Copy **`bananads-lan`** into **`store/apps/`** (replace the old folder) and **`BananaDS LAN.sh`** into **`store/tiles/`** on the shared **banana** folder. Do **not** replace the whole `store` folder.
3. Reboot once, open **Apps**, turn **On**, and set **Settings > Nintendo DS > Emulator** to **BananaDS**.

Your saves, save states, BananaDS settings and saved Nintendo WFC settings stay as they are. **`INSTALL.txt`** inside the zip has the detailed steps.

### Uninstall

Open BananaDS LAN and press **Y**. It turns itself off and removes its folder and tile, and your games go back to the BananaDS that came with BananaOS.

### Known limitations

- At 2x, heavy 3D scenes can drop the host below 60 fps: the host emulates the game and waits for every console's reply each frame. 1x is smoother.
- Supported only on **BananaOS 0.5.3.4** with the stock BananaDS hash in the app manifest. On other versions the app does not turn on and games keep the system BananaDS.
- Going online through Nintendo WFC with the system BananaDS (app Off) uses another DS identity. Play online with the app On.
- Multiplayer needs a low-latency path on your LAN; VPNs and tunnels are not supported.
