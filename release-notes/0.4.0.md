# BananaDS LAN 0.4.0

**BananaDS LAN** is an Apps-shelf app for BananaOS that runs its own BananaDS build with **local wireless multiplayer**. Consoles on the same Wi-Fi can host or join DS sessions from the in-game **Local multiplayer** menu.

This release is the **standalone emulator** line: a pixel **game library** on the shelf (grid or list, favorites, play time, covers), with **no mount** over the system BananaDS. Games launch on the app's own `emu/bananads` and return to the library when you quit.

**Devices:** Anbernic **RG DS** and **RG DS Plus**. Works on **BananaOS 0.5.2.2** and **0.5.3.4** with the stock BananaDS hashes recorded in the app manifest.

### What's new

- **Library first:** open Apps and pick a game from a sideways grid (X toggles a list; the mode is remembered), or resume from **Recent**.
- **Covers and stats:** ROM icons or covers when present, cumulative play time, last played, and save info on the focus card.
- **Favorites** share the same keys as BananaOS where possible; **START** opens settings (shader, scale, buttons) without leaving the shelf metaphor.
- **Navigation feel:** menu scroll sounds, held-direction repeat, touch-friendly scroll rails, and a single-tap launch row in list mode.
- **Sort A–Z** matches BananaOS title cleanup (`cleanTitle` + `game-titles.tsv`).
- **Updates row** can download and install a newer GitHub release with the same careful swap the Store uses.
- **One-file installer:** `Install-BananaDS-LAN.sh` goes into **`store/tiles`** once; open it from Apps and it copies the app to **`store/apps`**, installs the real tile, and deletes itself (no terminal).

### Install or update

**Option A — one file (recommended):**

1. Download **`Install-BananaDS-LAN.sh`** from this release.
2. Copy only that file into **`store/tiles`** on the shared **banana** folder. Do **not** replace the whole `store` tree.
3. Reboot once, open **Apps**, and run the installer tile. When it finishes, open **BananaDS LAN** from the new tile.

**Option B — zip (classic):**

1. Extract the zip. Copy **`bananads-lan`** into **`store/apps/`** and **`BananaDS LAN.sh`** into **`store/tiles/`**. Do **not** replace the whole `store` folder.
2. Reboot once and open **Apps**.

In **Settings > Nintendo DS > Emulator**, choose **BananaDS** if you still use the system menu for some titles; this app does not change that setting for other paths.

### Coming from 0.3.0

- Copy the new `bananads-lan` folder over the old one (or use the one-file installer). Saves, `.sav` files, BananaDS settings and WFC data stay under `/data/bananads-lan` and standard paths.
- The old **mount** mode is gone; you always get the library shell and the bundled BananaDS for games you pick here.

### Tested on

- RG DS and RG DS Plus on BananaOS 0.5.3.4: library navigation, LAN play between two consoles, lid close/resume, and OTA update install from the Updates row.

### Uninstall

Open BananaDS LAN, press **Y**, confirm with **A**. The app removes its folder and tile; games fall back to the BananaDS that shipped with BananaOS.

### Known limitations

- All consoles in a LAN session should run a compatible BananaDS LAN build on the same BananaOS generation.
- At 2x, heavy 3D scenes can drop the host below 60 fps during linked play; 1x is smoother.
- Going online through Nintendo WFC with the system BananaDS (while this app is off) uses another DS identity; play online with the app on if you need one profile.
- Multiplayer needs a low-latency LAN; VPNs and tunnels are not supported.
