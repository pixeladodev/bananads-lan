# BananaDS LAN 0.4.0 (emulator package)

This release is the **emulator runtime only**: a pinned **BananaDS** binary with **local wireless multiplayer** for consoles on the same Wi‑Fi. Shelf launchers (such as **Banana Lobby**) download this zip at package time and ship `emu/bananads` with the helper scripts beside it.

**Devices:** Anbernic **RG DS** and **RG DS Plus**. Built for **BananaOS 0.5.3.4**; the same binary hash is accepted on **BananaOS 0.5.2.2** when launchers pin it.

### What is in the zip

- **`emu/bananads`** — standalone emulator (does not replace `/usr/bin/bananads` on the console)
- **`run-emu`** — launch a title on this binary and return when the game exits
- **`lan.sh`** — turn local multiplayer preference on or off (`wifi.local` in the player config)
- **`status.sh`** — report whether the binary is present and the current LAN mode
- **`manifest`** — `app_version`, `binary_sha`, and source commit pins

### How launchers use it

Launchers verify `binary_sha` when they fetch `bananads-lan-<version>.zip` from GitHub releases. They copy the runtime files into their own app folder under `store/apps/…` and keep the system menu binary untouched.

### Build and verify

CI and tagged releases run `build/release-build.sh` in `debian:trixie-slim`. The compile must produce exactly the hash in `app/manifest`, or the release job fails.

### Local multiplayer

Default is **Auto** (in-game host/join). Use `lan.sh on|off` before launching if you want to force a mode. Consoles in one session should run the same emulator build.

### Tested on

RG DS and RG DS Plus on **BananaOS 0.5.3.4**: binary launch from a launcher app, local play between two consoles, lid close and resume.

### Known limitations

Heavy 3D scenes at high internal resolution can drop frame rate when one console hosts linked play. Stay on 1x for the smoothest sessions. Multiplayer expects a low-latency LAN, not VPN tunnels.

### Checksum pin

`app/manifest` records the exact `binary_sha` CI expects. Any rebuild that changes the bytes must bump `app_version` and update launchers that embed the zip.

### Script checks

`build/selftest.sh` covers shell syntax and `status.sh` with and without `emu/bananads`. `build/release-build.sh` runs selftest before packaging.

### Source pins

`superdrastic` and `melonds` in `app/manifest` select the upstream trees `release-build.sh` fetches. Patches under the SuperDrastic tree apply before compile.

### Packaging

`build/package.sh` writes only the `bananads-lan/` folder (no shelf tile, no installer script, no OTA updater). The outer zip name is `bananads-lan-<version>.zip`.

### Consumers

**Banana Lobby 0.1.x** pins this package (`emulator_version=0.4.0`, `binary_sha` in its manifest). Older published zips that still included a shelf UI are unchanged on GitHub; this tree is emulator-only going forward.
