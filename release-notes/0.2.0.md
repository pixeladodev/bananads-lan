# BananaDS LAN 0.2.0

**BananaDS LAN** is an Apps-shelf app for BananaOS that swaps in a build of BananaDS with local wireless multiplayer. Consoles on the **same Wi-Fi network** can host or join DS sessions from the in-game **Local multiplayer** menu.

This release follows **BananaOS 0.5.2.2**. Its BananaDS is the one BananaOS 0.5.2.2 ships, with Local multiplayer added on top, so you keep everything new in the system's BananaDS.

**Devices:** Anbernic **RG DS** and **RG DS Plus**. **BananaOS 0.5.2.2** only. On BananaOS 0.5.0.1, keep BananaDS LAN 0.1.0.

### What's new

- Built on **BananaOS 0.5.2.2's BananaDS**: faster and cooler at 3x and 4x, the per-game **Timing** ("Fast, DSi CPU"), and the **DS Pokémon companion** (alpha) when it is turned on in Settings.
- The **Buttons** page in Settings (Nintendo DS > Buttons) works in this BananaDS too: what L2, R2 and the stick clicks do, and Swap A/B and X/Y.
- The in-game menu keeps BananaOS 0.5.2.2's look and keys (F or HOME), with the **Local multiplayer** row in Quick settings. With every row shown, Quick settings still fits above the Back button.
- **Nintendo WFC** settings are kept between launches, with a DS MAC address of its own for each console, so online games keep the same WFC ID and friend code instead of asking to register again every time.

### Local multiplayer

- Works as in 0.1.0: **Auto** by default, or **Host** and **Join** on the Local multiplayer page.
- **Wi-Fi voice priority:** the session's packets are now sent in the Wi-Fi voice queue (DSCP 46), so most routers and access points put them ahead of the household's other traffic. Nothing to set up.
- **Optional direct link on home Wi-Fi (advanced, off by default):** adding `BANANADS_LAN_TDLS=1` to `/data/banana/bananads.env` on the host makes it ask for a TDLS link with each console that joins, so their packets skip the router. It lowers latency a little, but on the RG DS and RG DS Plus it also caused occasional disconnects in Mario Kart DS, so leave it off unless you want to experiment.
- All consoles in a session need BananaDS LAN 0.2.0 on BananaOS 0.5.2.2, or desktop melonDS on the same network.

### Install or update

1. Update the console to BananaOS 0.5.2.2 first (Settings > System > Update).
2. Extract the zip. Copy **`bananads-lan`** into **`store/apps/`** (replace the old folder) and **`BananaDS LAN.sh`** into **`store/tiles/`** on the shared **banana** folder. Do **not** replace the whole `store` folder.
3. Reboot once, open **Apps**, turn **On**, and set **Settings > Nintendo DS > Emulator** to **BananaDS**.

Your saves, save states, BananaDS settings and saved Nintendo WFC settings stay as they are. **`INSTALL.txt`** inside the zip has the detailed steps.

### Tested on

- An RG DS and an RG DS Plus on BananaOS 0.5.2.2, each console as host, over home Wi-Fi (5 GHz access point).
- Mario Kart DS balloon battles at 2x: about 55 fps on the host with no disconnects with the defaults of this release.

### Uninstall

Open BananaDS LAN and press **Y**. It turns itself off and removes its folder and tile, and your games go back to the BananaDS that came with BananaOS.

### Tip

- If a console runs slower as the host, check its BananaDS settings: an old fixed `core.slice = 64` line in `/data/bananads/bananads.conf` makes 2x slower than the default (`auto`).

### Known limitations

- At 2x, heavy 3D scenes can drop the host below 60 fps: the host emulates the game and waits for every console's reply each frame. 1x is smoother.

- Supported only on **BananaOS 0.5.2.2** with the stock BananaDS hash in the app manifest. On other versions the app does not turn on and games keep the system BananaDS.
- Going online through Nintendo WFC with the system BananaDS (app Off) uses another DS identity. This app's saved WFC settings are not touched, but a game may treat that session as another console and change its own friend data. Play online with the app On.
- Multiplayer needs a low-latency path on your LAN; VPNs and tunnels are not supported.
