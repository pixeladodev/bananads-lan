# bananads-lan 0.1.0

**Emulator package only** — not a BananaOS shelf app. This zip is what **Banana Lobby** (and other hosts) bundle at package time: a pinned **BananaDS** build with **local wireless multiplayer** on the same Wi‑Fi.

**Devices:** Anbernic **RG DS** and **RG DS Plus**. Built for **BananaOS 0.5.3.4** (also used on **BananaOS 0.5.2.2** when launchers pin this hash).

### Zip contents

- `bananads-lan/emu/bananads` — standalone player binary (does not replace `/usr/bin/bananads`)
- `run-emu`, `lan.sh`, `status.sh`, `common.sh`, `manifest`

No shelf tile, no one-file installer, no on-screen library, no OTA updater.

### How hosts use it

Launchers download `bananads-lan-0.1.0.zip`, verify `binary_sha` in their manifest against `emu/bananads`, and copy the runtime into their app folder under `store/apps/…`.

### Local multiplayer

Default is in-game **Auto**; `lan.sh on|off` adjusts `wifi.local` before launch. Session consoles should share this build.

### Build

CI runs `build/release-build.sh` in `debian:trixie-slim`. The compile must match `binary_sha` in `app/manifest` or the job fails.

### Tested on

RG DS and RG DS Plus on **BananaOS 0.5.3.4**: fetch from GitHub, verify hash, launch through **Banana Lobby**, two-console local play.

### Known limitations

At high internal resolution the host can drop frames in heavy 3D during linked play; 1x is smoother. Multiplayer expects a low-latency LAN, not VPN tunnels.

### Checksum pin

`app/manifest` records the exact bytes CI expects. Any rebuild that changes the hash must bump `app_version` and update consumers.

### Script checks

`build/selftest.sh` covers shell syntax and `status.sh` with and without `emu/bananads`. Release builds run selftest before `build/package.sh`.

### Source pins

`superdrastic` and `melonds` keys in `app/manifest` select the trees `release-build.sh` fetches. Patches apply before compile (see `build/apply-patches.sh`).

### Packaging layout

`build/package.sh` writes a single top-level folder `bananads-lan/` inside `bananads-lan-<version>.zip`.

### First public emulator release

Earlier GitHub releases that shipped a shelf UI were removed. This tag is the first emulator-only artifact.
