# bananads-lan 0.1.1

**Emulator package only** — not a BananaOS shelf app. This zip is what **Banana Lobby** bundles at package time: a pinned **BananaDS** build with **local wireless multiplayer** on the same Wi-Fi.

**Devices:** Anbernic **RG DS** and **RG DS Plus**. Built for **BananaOS 0.5.3.4**.

This tag replaces the 0.1.0 binary. Hosts that pin `binary_sha` must take this hash. The bytes are the player built from the SuperDrastic commit named in `app/manifest`, the same source that was checked on the handheld, not an older pin with a draft tree copied over it.

### What changed

- A lobby room is one long-lived process. It starts fresh. It does not load the resume slot, and leaving the room does not write that slot. Powering the console off still writes it.
- The wide row under the six tiles is Local multiplayer. Brightness stays on Quick settings.
- Auto discovery is the host app's setting. A game opened while the room is off and discovery is on uses Auto for that game only. Auto is not written back as the saved mode. When the game ends, an Auto session returns to Off.
- The room lets go of the sound device when a game ends, so the host app can play its own sounds again.

### Zip contents

- `bananads-lan/emu/bananads` — the player binary (does not replace `/usr/bin/bananads`)
- `run-emu`, `lan.sh`, `status.sh`, `common.sh`, `manifest`

No shelf tile, no second installer, no on-screen library, no updater. One zip is the install file hosts copy.

### How hosts use it

Download `bananads-lan-0.1.1.zip`, verify `binary_sha` in `app/manifest` against `emu/bananads`, and copy the runtime into the app folder under `store/apps/…`.

### Local multiplayer

`lan.sh on|off` adjusts `wifi.local` before a game. Consoles in one session should share this build.

### Build

CI runs `build/release-build.sh` in `debian:trixie-slim`. The compile must match `binary_sha` or the job fails. Link-time optimization stays at 12 partitions so a laptop and the runner hash the same bytes. Compile jobs are capped at 80 percent of the CPU count.

### Tested on

RG DS on **BananaOS 0.5.3.4**: the lobby room, a game launched from Banana Lobby, and local play between consoles.

### Known limitations

At high internal resolution the host can drop frames in heavy 3D during linked play; 1x is smoother. Multiplayer expects a low-latency LAN, not VPN tunnels.

### Checksum pin

`app/manifest` records the exact bytes CI expects. A rebuild that changes the hash must bump `app_version`.

### Script checks

`build/selftest.sh` covers shell syntax and `status.sh` with and without `emu/bananads`. Release builds run selftest before `build/package.sh`.

### Source pins

`superdrastic` and `melonds` in `app/manifest` are the trees `release-build.sh` fetches. Patches apply before compile (`build/apply-patches.sh`).

### Packaging layout

`build/package.sh` writes one top-level folder, `bananads-lan/`, inside `bananads-lan-0.1.1.zip`.
